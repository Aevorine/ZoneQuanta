# SPEC — ZoneQuanta
> 「现在」的唯一事实源。稳定知识在 README.md，长期方向在 .claude/TECH_ROADMAP.md，规则在 .claude/CLAUDE.md。

## 当前目标
Windows 桌面时钟组件（本地 + 洛杉矶），WPF / .NET 8 单文件 exe。验收标准：
1. 鼠标穿透、总是置顶、锁定位置、允许超出屏幕、全屏时隐藏、开机自启，均有开关且立即生效
2. 托盘左键显示 / 隐藏面板（隐藏后任务栏无图标），右键含常用开关；全局快捷键切换面板
3. 在线更新：多线路并发 + 分段下载，签名与 SHA-256 校验，原地替换重启
4. 界面风格统一、护眼、可扩展（页面注册表、时区列表数据化）
5. 公开仓库 Aevorine/ZoneQuanta，Releases 只保留最近两版

### T-20261105-1 第十七轮验收（v1.8.0，71–76）
> 用户反馈：① 快捷面板弹出的界面（文件夹视图）不容易退出，要能点空白等处关闭；② 快捷面板与弹出界面要能三指下滑退出；③ 拖动分组移动位置时，分组之间位置变化过快、难以确定落点，且其他图标 / 分组的位置跟着错乱。根因：① 用户视图为自定义 1460×730，几乎铺满面板，可点的只剩四周 24 px 遮罩、右上角 ×、Esc；顶栏、窗口边距、视图内大片空白都不响应；② Windows 自己处理三指手势（默认下滑 = 显示桌面），从不转给应用，必须读触摸板 / 触摸屏的原始 HID 触点；③ 目标格是指针坐标直接四舍五入、无迟滞无停留，指针每过半格整板重排；被拖卡片以最高优先级钉住，压到的已钉卡片被一路向下推（级联），且它们存的位置与显示不再一致，之后的拖动又会让未碰过的卡片跳回 / 跳走（2026-11-06）。
