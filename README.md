# ZoneQuanta

<img src="docs/icon.png" alt="ZoneQuanta icon" width="96" align="right">

**中文** · [English](README.en.md)

**Windows 桌面世界时钟 + 任务栏网速 / CPU / 内存监控 + 应用流量统计与额度 + 快捷面板** · Windows desktop world clock (Los Angeles / local / any city, automatic DST), taskbar network-speed, CPU and RAM monitor, and per-app traffic statistics. Lightweight WPF / .NET 8, single-file exe, signed auto-update.

> 关键词 / Keywords: world clock, time zone, DST, Los Angeles time, desktop widget, taskbar monitor, network speed meter, upload download speed, CPU usage, memory usage, per-app network traffic, bandwidth monitor, Windows 10, Windows 11, WPF, .NET 8, 桌面时钟, 世界时钟, 夏令时, 洛杉矶时间, 任务栏网速, 流量统计

## v1.3.0

这一版专注「显示速度」。时钟改由独立高精度线程在整秒前约 12 ms 唤醒，并在界面线程最先绘制，不再排在网卡采样和监控条重排之后；实测文字在秒翻转前约 11 ms 就绪，旧版平均晚 13 ms，CPU 满载时旧版最长停顿 10 秒、新版无停顿（进程不再被降为低优先级，也退出了 Windows 11 的效率模式节流）。网速 / CPU / 内存改在后台线程采样，默认 0.5 秒刷新一次，可在「监控」页改为 0.25 / 1 / 2 秒；监控条被收起、面板关闭时自动降为每秒采样。

任务栏监控条：自动隐藏的任务栏在隐藏期间预先读好布局，重新出现后几毫秒内显示（旧版首次约 0.8 秒）；布局变化时不再先收起再重算；数值只替换文字，不再每次重新做字号搜索；悬停详情改为鼠标事件驱动并预先创建窗口，约 10 ms 弹出。全屏与「回到桌面」的判断改为前台窗口变化时立即执行。

同时修复：每 30 秒刷新网卡列表时会出现一次 0 速度并丢失这一秒的流量；应用流量统计的后台任务丢失时开关仍显示为开启，现在会提示并关闭；日志达到上限时不再整份清空。托盘菜单新增「任务栏监控条」开关。


## 安装

在 [Releases](https://github.com/Aevorine/ZoneQuanta/releases/latest) 下载 `ZoneQuanta.exe`（约 165 MB），双击即可使用：**已内置 .NET 运行时和全部依赖，不需要再安装任何东西**。

首次运行会询问安装位置：**可自行选择任意目录，程序始终安装在其中的 `ZoneQuanta` 文件夹内**（例如选择 `D:\Apps`，实际安装到 `D:\Apps\ZoneQuanta`），并可选创建桌面快捷方式与开机自启。程序未做代码签名，SmartScreen 可能提示未知发布者，选择「仍要运行」。

## 应用流量统计说明

Windows 只允许管理员读取按进程划分的网络事件，因此该功能是**可选的**：在「流量」页打开开关后，会弹出一次系统授权，创建名为 `ZoneQuantaTraffic` 的计划任务，用管理员权限运行统计助手（基于 ETW `Microsoft-Windows-Kernel-Network`，只记录进程名与字节数，不读取内容）。关闭开关时删除该任务。不开启时，仍可看到全部流量的总量与实时网速。

使用本地代理（如 TUN / 系统代理）时，流量会归属到代理进程。

## 使用

- 托盘图标 **左键** 打开 / 收起面板，收起后任务栏不显示；**右键** 是常用开关、快捷面板、打开路径和快捷项列表
- 面板分十页：控制台、显示、时区、监控、流量、快捷、快捷键、窗口、系统、更新；按住导航栏任意位置（导航项、空白处、版本号）直接拖动即可移动面板，单击导航项仍切换页面；按住导航项约 0.3 秒不动再上下拖动可调整顺序（右键导航「恢复默认顺序」）；双击导航空白处最大化 / 还原；最大化时拖动导航会还原并跟随指针，拖到屏幕边缘可贴靠
- 快捷面板：四周边距、顶栏空隙、按钮、搜索框空白处都可直接拖动窗口（单击仍是单击）；按在已输入的文字上拖动是选中文字，按住约 0.3 秒再拖才移动窗口；双击边距或顶栏空隙最大化 / 还原
- 分组卡片：按住卡片（或组名）拖到任意格子，其他卡片实时让位，松开即固定；Esc 取消；右键组名「取消固定位置」「全部自动排列」「按内容命名」；拖到面板上下边缘自动滚动
- 组合应用：把图标拖到另一个图标上，新组按功能自动命名（同类用类别名，两类用「A与B」，否则用共同厂商或「常用」），直接回车接受或输入新名称
- 快捷面板与主面板都记住上次的大小、位置、最大化状态，主面板还记住上次打开的页面（电脑重启、注销、关机、自动更新后照旧，换显示器或分辨率时按比例放到同一位置并保证完整可见）；拖动边缘时面板中央实时显示像素大小；「快捷」页「打开位置」可选上次位置 / 屏幕中央 / 跟随指针，右侧显示已记住的大小，↺ 恢复默认大小
- 导航栏：左下角 ‹ 或 `Ctrl + B` 收起为仅图标 / 展开，状态记住；指针停在图标上显示功能名称与该页内容
- 页面内容：按住卡片、开关行或空白处一移动就拖动面板；按住约 0.3 秒不动再拖，卡片 / 开关行浮起，拖到新位置松开即保存（重启、更新后保持）；空白处右键「恢复默认布局」
- 「流量」页：「进程 / 应用」切换每个进程一行或同一应用合并为一行；悬停看路径与成员用量；右键「打开文件位置」「复制路径」「属性」
- 历史版本：程序在启动、退出、更新前、恢复前和每次改动后自动保存设置与快捷面板（相同内容不重复，保留最近 60 份 + 30 天内每天 1 份）；「系统」页「历史版本」看时间、原因与改动，点 ↺ 再点「确认恢复」回到该版本（先保存当前版本，程序自动重启）；+ 立即保存一份，文件夹按钮打开历史文件夹
- 设置、日志与统计数据在 `%APPDATA%\ZoneQuanta`（快捷面板条目在 `quick.json`，历史版本在 `history\`）

| 快捷面板内 `Enter` / `Ctrl + Enter` / `F2` / `Del` / `Ctrl + C` | 打开 / 打开所在位置 / 重命名 / 移除 / 复制路径（除 Enter 外均可在「快捷键」页改写） |
| 快捷面板内 `Ctrl + Z` / `Ctrl + Y`（或 `Ctrl + Shift + Z`） | 撤销 / 重做（添加、移除、移动、分组、改名，最多 50 步） |
| 面板内 `Ctrl + B` | 收起 / 展开导航栏 |
| 打开路径内 `Tab` / `↑↓` / `Enter` / `Ctrl + Enter` / `Shift + Enter` / `Esc` | 补全 / 选择 / 打开 / 打开所在位置 / 加入快捷面板 / 清空或关闭 |

### 快捷面板操作步骤

1. 首次启动会自动导入「开始」屏幕固定的全部应用；之后在「开始」新固定的应用几秒内自动加入（「快捷」页「同步「开始」固定的应用」可关闭，「添加 → 从「开始」导入」可找回已移除的）
2. 在资源管理器中右键文件或文件夹 → 「添加到快捷面板」（Windows 11：先点「显示更多选项」，或按住 Shift 再右键）；也可在「快捷」页点「添加文件」「添加文件夹」，或把文件拖进面板
3. 按 `Ctrl + Alt + Space` 呼出面板（拖动边缘调整大小、拖动位置、最大化都会被记住，下次在同一位置以同样大小打开），单击图标打开；输入文字即时筛选，回车打开第一项；输入的是路径则直接打开该路径
4. 分组：新加入的项会自动归入合适的组；右键图标「移到分组」、把图标拖到卡片上、拖到另一个未分组图标上（两者组成新组并命名）、拖到空白处（移出分组）都算手动分类，之后自动分类不会再改它；右键组名可重命名、设卡片大小、展开 / 收起、解散分组；拖动卡片调整组的顺序；鼠标移到卡片上后拖动右下角手柄按整格调整「列 × 行」
5. 右键图标选择其他操作；按住拖动可调整顺序（排序为「自定义」时）
6. 「快捷」页的芯片按钮决定显示哪些信息（图标、名称、路径、类型、大小、修改时间、打开次数），开关决定右键菜单、打开后自动收起、托盘列表与两个快捷键是否启用

### 修改快捷键

1. 面板进入「快捷键」页，点击要改的输入框，按下新的组合（全局快捷键需含 Ctrl / Alt / Win；面板内快捷键可用单键如 F3）
2. 与其他项重复会被拒绝并提示与哪一项相同；右侧开关关闭全局快捷键；↺ 恢复默认
3. 设置立即生效并保存在 `%APPDATA%\ZoneQuanta\settings.json`，重启后保持

### 流量额度操作步骤

1. 「流量」页点右上角额度卡片，打开「流量额度」开关，填每月额度（GB）并拖动选择重置日
2. 额度卡片显示剩余与已用比例；切到「每日」查看本账期逐日用量、每日可用线与预测；范围选「账期」时上方统计与应用排行按账期计算
3. 打开「用量提醒」并选择阈值，到达阈值和用完时托盘各提醒一次

### 命令行（脚本与 Claude Code 可调用）

程序已在运行时，再次启动并带参数会把命令交给正在运行的实例，然后立即退出：

| 命令 | 作用 |
|---|---|
| `ZoneQuanta.exe --quick-add <路径> [<路径> …]` | 把文件 / 文件夹加入快捷面板（相对路径按当前目录解析） |
| `ZoneQuanta.exe --quick` | 显示快捷面板 |
| `ZoneQuanta.exe --path-bar` | 显示打开路径输入框 |
| `ZoneQuanta.exe --open <路径或网址>` | 打开路径（同输入框规则：引号、环境变量、`shell:`、网址） |
| `ZoneQuanta.exe --panel [页面名]` | 打开面板，可直接跳到某页，如 `--panel 流量` |
| `ZoneQuanta.exe --exit` | 正常退出正在运行的实例（先保存设置与窗口位置） |
| `ZoneQuanta.exe --data-dir <目录> [其他命令]` | 在隔离的数据目录上运行一个独立实例（测试、演示用：不注册快捷键与右键菜单、不启动统计助手、不安装更新，不碰真实数据）；也可设环境变量 `ZONEQUANTA_DATA` |

日志 `%APPDATA%\ZoneQuanta\app.log` 精确到毫秒，记录快捷面板的添加 / 移除 / 移动 / 分组 / 改名 / 撤销、每次保存的设置项、历史版本的保存与恢复、导航收起、应用图标解析耗时、快捷键冲突与回退、额度提醒、右键菜单注册等，便于排查与后续升级。

## 架构

```
src/ZoneQuanta
├── Core        纯逻辑，不依赖界面
│   ├── Settings   设置模型与持久化
│   ├── Time       时区计算、夏令时、日出日落（天文算法）、城市目录、整秒前触发的高精度计时器
│   ├── Monitor    后台采样线程（网速 / CPU / 内存）、单位换算、流量存储、额度与账期计算
│   ├── Quick      快捷面板条目存储（使用热度）、路径解析与补全、模糊匹配
│   ├── Traffic    管理员统计助手（ETW）与计划任务启动器
│   └── Update     清单验证、并行下载、更新协调
├── Platform    Win32 封装：窗口样式、全屏检测、前台窗口监听、任务栏跟踪与布局、全局热键、开机自启、系统图标、资源管理器右键菜单、命令管道
├── Shell       托盘
├── UI
│   ├── Theme      调色板与统一样式
│   ├── Controls   滚动数字、24 小时日轴、速度曲线、时区卡片、额度环、逐日柱状图、快捷键输入框
│   ├── Widget     桌面组件窗口
│   ├── Band       任务栏监控条
│   ├── Quick      快捷面板、打开路径输入框、条目网格
│   ├── Setup      安装窗口
│   └── Panel      设置面板（页面注册表，新增页面只需加一行）
└── AppController  组合根
```

## 构建

需要 .NET 8 SDK：`dotnet build src/ZoneQuanta -c Release`。发布流程见 `scripts/release.ps1`（构建自带运行时的单文件、签名更新清单、创建 Release、仅保留最近两个版本）。签名私钥不在仓库中。
