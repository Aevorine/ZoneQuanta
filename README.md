# ZoneQuanta

<img src="docs/icon.png" alt="ZoneQuanta icon" width="96" align="right">

**中文** · [English](README.en.md)

**Windows 桌面世界时钟 + 任务栏网速 / CPU / 内存监控 + 应用流量统计** · Windows desktop world clock (Los Angeles / local / any city, automatic DST), taskbar network-speed, CPU and RAM monitor, and per-app traffic statistics. Lightweight WPF / .NET 8, single-file exe, signed auto-update.

> 关键词 / Keywords: world clock, time zone, DST, Los Angeles time, desktop widget, taskbar monitor, network speed meter, upload download speed, CPU usage, memory usage, per-app network traffic, bandwidth monitor, Windows 10, Windows 11, WPF, .NET 8, 桌面时钟, 世界时钟, 夏令时, 洛杉矶时间, 任务栏网速, 流量统计

## 特性

| 能力 | 说明 |
|---|---|

| 热门国家与城市 | 内置 36 个热门城市（美国、加拿大、中国、日本、欧洲、澳洲等），另可从系统全部时区中搜索，最多同时显示 4 个，可改名、排序 |

## v1.2.19

修复原生任务栏宿主中的文字被裁切或看起来空白的问题。根控件在布局尚未完成时可能返回过期或零测量尺寸，上一版因此选择了过大的字号。现在直接测量每个标签与数值的文字尺寸，累计真实宽高，再选择安全区域内最大的可用字号；宿主尺寸确定后显式执行 Measure / Arrange / UpdateLayout，保持 HwndSource 手动尺寸模式。

本轮在相同渲染代码上完成了诊断：125% DPI 下六项内容完整显示，改变数值后重新测量无裁切；私有诊断父窗口移动与隐藏时，子窗口即时继承对应变化。诊断没有移动系统任务栏，也没有保存整个桌面。图标避让与自动隐藏期间的安全区域缓存继续保留。

## v1.2.18

任务栏监控内容改为由 `HwndSource` 创建的原生子窗口，坐标直接相对于任务栏；任务栏移动、显示和隐藏时，由 Windows 的父子窗口机制带动内容，不再靠独立浮窗追赶动画。自动隐藏滑动期间保留已识别的安全区域，不将动画中的控件位置事件当成图标布局变化，也不等待后台识别才重新显示。真正的图标布局变化仍重新识别以避免遮挡。

字体取消固定的小字号上限，按实际文字尺寸和安全区域的宽高寻找可完整显示的最大字号，标签与数值一起调整。测量前清除上一次宿主的固定宽高，防止把窗口尺寸误当成文字尺寸。保留上下边界与按钮间距，字号使用半 DIP 步进，剩余横向空间分配到可见项。任务栏重建后重新创建子窗口。

## v1.2.17

修正字体过大的问题：任务栏字号以 Windows 界面字体为基准，数值保持 9–16 DIP 的合理范围，标签为 8–11 DIP；任务栏较矮或宽度不足时，根据实际文字测量缩小。字号采用半 DIP 步进，减少数字变化带来的跳动。上下与横向均保留测量余量，文字不再为了填满空白而无限放大；剩余空间用于间距，继续避让开始和应用图标。

## v1.2.16

任务栏字体按空闲区域的宽度与任务栏高度自动调整。程序测量当前文字的实际尺寸，选择能完整显示的最大字号；取消固定的宽列和只缩小的限制，剩余横向空间均匀分配，减少四周留白。开始按钮、应用图标与通知区的安全间距继续保留。关闭部分监控项、切换单位或文字变长时重新计算，位置跟随期间复用测量结果。

## v1.2.15

任务栏监控条按开始按钮、应用按钮、搜索及通知区的实际边界寻找空闲区域，留出安全间距，并按可用宽度整体缩小。位置微调只在空闲区域内生效，不能再把监控条推到图标上。应用按钮或任务栏布局变化时先收起旧位置，再重新计算；识别工作在后台完成，不占用任务栏动画的位置跟随线程。空间过窄、布局无法可靠识别或使用竖向任务栏时，暂时收起监控条；桌面时钟与托盘面板仍可使用。

## v1.2.14

任务栏顺序为上传、下载、**今日流量**、总速、内存、CPU；今日流量默认启用，可在监控页单独关闭，按本机日期累计已记录的上传与下载字节，重启后继续累计。单位自动换算为 B / KB / MB / GB，与速度的比特和固定单位设置独立。统计只覆盖程序运行期间选定网卡的流量；历史数据按小时存储，非整点时区的日期边界精度为一小时。

监控条通过 Windows 窗口事件跟随任务栏显示、隐藏和移动，另有 16 ms 的轻量位置检查补充未发送事件的动画；位置跟随不再等待每秒数据采样。窗口按任务栏所在屏幕裁剪，完全隐藏时不保留边缘监控条，并自动恢复 Explorer 重启后的跟随。

## 安装

在 [Releases](https://github.com/Aevorine/ZoneQuanta/releases/latest) 下载 `ZoneQuanta.exe`（约 165 MB），双击即可使用：**已内置 .NET 运行时和全部依赖，不需要再安装任何东西**。

首次运行会询问安装位置：**可自行选择任意目录，程序始终安装在其中的 `ZoneQuanta` 文件夹内**（例如选择 `D:\Apps`，实际安装到 `D:\Apps\ZoneQuanta`），并可选创建桌面快捷方式与开机自启。程序未做代码签名，SmartScreen 可能提示未知发布者，选择「仍要运行」。

## 应用流量统计说明

Windows 只允许管理员读取按进程划分的网络事件，因此该功能是**可选的**：在「流量」页打开开关后，会弹出一次系统授权，创建名为 `ZoneQuantaTraffic` 的计划任务，用管理员权限运行统计助手（基于 ETW `Microsoft-Windows-Kernel-Network`，只记录进程名与字节数，不读取内容）。关闭开关时删除该任务。不开启时，仍可看到全部流量的总量与实时网速。

使用本地代理（如 TUN / 系统代理）时，流量会归属到代理进程。

## 使用

- 托盘图标 **左键** 打开 / 收起面板，收起后任务栏不显示
- 面板分八页：控制台、显示、时区、监控、流量、窗口、系统、更新
- 设置、日志与统计数据在 `%APPDATA%\ZoneQuanta`

## 架构

```
src/ZoneQuanta
├── Core        纯逻辑，不依赖界面
│   ├── Settings   设置模型与持久化
│   ├── Time       时区计算、夏令时、日出日落（天文算法）、城市目录、秒对齐计时器
│   ├── Monitor    网速 / CPU / 内存采样、单位换算、流量存储
│   ├── Traffic    管理员统计助手（ETW）与计划任务启动器
│   └── Update     清单验证、并行下载、更新协调
├── Platform    Win32 封装：窗口样式、全屏检测、全局热键、开机自启
├── Shell       托盘
├── UI
│   ├── Theme      调色板与统一样式
│   ├── Controls   滚动数字、24 小时日轴、速度曲线、时区卡片
│   ├── Widget     桌面组件窗口
│   ├── Band       任务栏监控条
│   ├── Setup      安装窗口
│   └── Panel      设置面板（页面注册表，新增页面只需加一行）
└── AppController  组合根
```

## 构建

需要 .NET 8 SDK：`dotnet build src/ZoneQuanta -c Release`。发布流程见 `scripts/release.ps1`（构建自带运行时的单文件、签名更新清单、创建 Release、仅保留最近两个版本）。签名私钥不在仓库中。
